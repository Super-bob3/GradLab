# 形态与流动

形态与流动定义了驱动渐变运动和形态的底层数学结构。每种算法以 GLSL 片段着色器的形式直接运行于 GPU，即便是复杂图案也能流畅渲染 60fps 动画。

## 算法列表

### 经典与周期性

| 算法 | 特点 |
|------|------|
| **经典正余弦** | 平滑的周期性波动渐变，最稳定的起点，适合平静流动的风格。 |
| **结构化映射（有序阵列）** | 有组织的网格状空间映射，产生有序的几何渐变结构。 |
| **线性竖向分层** | 带有细微变化的水平分层条带 — 干净、建筑感。 |

### 有机与混沌

| 算法 | 特点 |
|------|------|
| **流体力学（混沌）** | 基于分层噪声模拟湍流运动，高熵、有机、不可预测。 |
| **域扭曲（大理石）** | 迭代扭曲 UV 坐标，产生大理石纹脉和折叠结构。 |
| **卷曲噪声（漩涡）** | 从噪声场的旋度导出运动 — 平滑的无散度漩涡流。 |
| **极地漩涡（宇宙）** | 极坐标与噪声结合，产生宇宙螺旋结构。 |

### 拓扑与几何

| 算法 | 特点 |
|------|------|
| **径向等高线** | 从画布中心向外辐射的同心环，类似等高线地图或声波可视化。 |
| **圆锥角向扫描** | 基于极角的颜色扫描 — 扇形分区配平滑渐变过渡。 |
| **嵌套 SDF 形态（核心光晕）** | 使用有符号距离场数学渲染带发光核心的几何形状，干净、锐利、雕塑感。 |

### 弥散

| 算法 | 特点 |
|------|------|
| **弥散渐变（柔和有机）** | 纯程序弥散 — 柔和的自然色彩扩散，无硬边。 |
| **弥散流体（图片纹理）** | 上传背景图片，弥散场将其扭曲融入渐变流场。 |
| **弥散流体（多点 SDF）** — 以多点有符号距离场为弥散源 — 几何而有机。 |

## 运动控制

| 参数 | 效果 |
|------|------|
| **速度** | 动画推进速度。0 为冻结画面，数值越高运动越快。 |
| **缩放** | 图案的空间比例 — 放大看细节，缩小看全局结构。 |
| **液化** | 在算法的结构化输出与流体噪声层之间混合，为几何图案增加有机流动感。 |
| **形变** | 上下文相关 — 在波动类算法上调整波形失真，在 SDF 形态上变形基础几何体。 |
