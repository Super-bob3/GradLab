# 后期处理

后期处理效果作为合成通道叠加在渐变之上，是无损的 — 调整或禁用这些效果不会改变底层着色器的输出。

## 胶片颗粒

胶片颗粒在画布上叠加一层模拟噪声，模仿胶片或印刷介质的质感。

- **强度** — 控制颗粒的可见程度，从几乎不可察觉的质感到明显的噪点
- **混合模式** — 决定颗粒与下方渐变的叠加方式

| 混合模式 | 效果 |
|---------|------|
| **叠加** | 颗粒提亮高光、压暗阴影 — 最自然的胶片质感 |
| **滤色** | 颗粒只提亮，产生发光朦胧感 |
| **正片叠底** | 颗粒只压暗，增加深度和质感 |

::: tip
强度 15–25、叠加模式的颗粒可为渐变带来微妙的触感，印刷效果尤为出色。
:::

## 内边框

在画布边缘内侧添加柔和晕影或硬边框架，增强视觉纵深感，将焦点集中于中心区域。适合需要渐变不延伸至画面边缘的社交媒体格式。

## 圆角

对画布四角进行圆角处理。导出的 PNG 和 HTML 均遵循圆角设置，可直接用于圆角 UI 组件，无需额外遮罩。

- **0** — 直角
- 数值越大，圆角越大，最大值时为圆形

## 3D 倾斜

为画布添加随鼠标移动响应的透视扭曲效果，光标在页面上移动时，渐变沿 X、Y 轴倾斜，产生视差纵深感。

::: info
3D 倾斜为预览专属效果，不影响 PNG 和视频导出的内容。
:::
