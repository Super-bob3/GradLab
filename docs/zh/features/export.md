# 导出

GradLab 提供三种导出格式。所有导出均捕获完整的合成输出 — 渐变、半调、ASCII 矩阵与颗粒 — 以原生渲染分辨率（最低 2× 设备像素比）输出。

## PNG 截图

**下载帧**捕获当前画布状态为 PNG。

- 分辨率与 WebGL 渲染缓冲区一致，最低 2× 设备像素比
- 包含所有激活的图层：渐变、半调、ASCII 矩阵与胶片颗粒
- 若启用圆角，圆角信息嵌入 PNG Alpha 通道
- 即时导出，无处理延迟

**适合：** 设计稿、社交媒体、UI 原型图或印刷素材。

## 视频录制

**录制 MP4** 捕获动画的实时视频。

1. 点击**录制 MP4** 开始录制 — 按钮显示已录制时长
2. 录制完成后点击**停止**
3. GradLab 对捕获的帧进行编码并自动下载

| 设置 | 选项 |
|------|------|
| **格式** | 支持时导出 MP4（H.264），否则回退至 WebM（VP8） |
| **乒乓循环** | 启用后，录制内容正放后倒放，形成无缝无限循环 |

::: info
如果要将视频用作循环背景，请在开始录制前启用**乒乓循环**。生成的文件在循环点处无可见的跳切。
:::

**录制技巧：**
- 录制 3–8 秒并使用乒乓循环 — 文件更小，效果更好
- 录制前降低**速度**，获得更舒缓的氛围感循环
- 禁用 **3D 倾斜** — 该效果与屏幕相关，导出时会产生不一致的运动

## HTML 代码导出

**导出代码**生成一个完全独立的 `.html` 文件，包含：

- 完整的 WebGL 着色器源代码
- 所有当前参数值，以 uniform 形式内嵌
- 画布渲染循环
- 无任何外部依赖 — 可在任意浏览器离线运行

生成的 HTML 可以：
- 通过 `<iframe>` 嵌入任意 Web 项目
- 作为独立全屏背景使用
- 直接以文件形式在任意浏览器中打开
- 作为包含完整视觉状态的单文件进行分享

::: tip
导出的 HTML 是当前参数设置的快照。调整渐变后需重新导出 — HTML 文件与应用之间没有实时链接。
:::

## 分辨率说明

GradLab 以 `Math.max(2, devicePixelRatio)` 渲染，保证所有平台输出一致：

- **Mac（Retina）：** 根据显示器为 2× 或 3×
- **Windows（标准 DPI）：** 无论系统 DPI 设置如何，均以 2× 渲染
