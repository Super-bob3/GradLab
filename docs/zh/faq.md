# 常见问题

## 基本问题

**GradLab 是免费的吗？**

是的。GradLab 完全免费，直接在浏览器中运行，无需注册账号。

**需要安装任何软件吗？**

不需要。GradLab 是一个 Web 应用 — 打开网址即可开始使用。无需插件、无需桌面客户端、无需任何依赖。

**支持哪些浏览器？**

任何支持 WebGL 的浏览器均可使用：桌面端和移动端的 Chrome、Firefox、Safari 和 Edge。视频录制方面，Chrome 和 Edge 提供最佳编解码支持（MP4/H.264），Safari 导出 WebM 作为备选。

**我的作品会自动保存吗？**

GradLab 基于会话存储 — 页面打开期间设置会保留。如需长期保存配置，使用**导出代码**保存一个内嵌所有参数的独立 HTML 文件。

## 导出与质量

**导出的 PNG 分辨率是多少？**

PNG 导出与 WebGL 渲染缓冲区一致，以 `Math.max(2, devicePixelRatio)` 渲染。在标准显示器上，最大化浏览器窗口导出的图片分辨率约为屏幕分辨率的两倍。Retina/HiDPI 显示器上分辨率更高。

**可以导出透明 PNG 吗？**

目前不支持。画布在纯色背景上渲染。透明效果可在任意图像编辑器中，以圆角 Alpha 通道为起点添加。

**我的视频导出是 WebM 而不是 MP4，为什么？**

MP4（H.264）编码需要 MediaRecorder H.264 支持，不同浏览器支持情况不同。Safari 和部分 Firefox 配置会回退至 WebM（VP8）。两种格式都广泛兼容，WebM 在所有现代浏览器中均可原生播放。

## 性能

**动画出现卡顿怎么办？**

尝试降低**速度**滑块，并在启用状态下禁用 **ASCII 字符矩阵** — 字符网格在字号较大时对 CPU 占用较高。关闭其他 GPU 密集型浏览器标签页也有帮助。

**GradLab 支持移动端吗？**

支持。WebGL 引擎可在移动端浏览器运行。由于 MediaRecorder API 限制，iOS 暂不支持视频录制。PNG 导出和 HTML 导出在所有平台均可正常使用。

## 使用场景

**我可以在商业项目中使用 GradLab 的导出文件吗？**

可以。导出文件归你所有，无版权水印，导出的 PNG、视频和 HTML 文件均无任何使用限制。

**如何将渐变嵌入我的网站？**

使用**导出代码**获取独立 HTML 文件，然后通过 `<iframe>` 嵌入你的页面。将 iframe 的 `width` 和 `height` 设置为 `100%` 即可实现全出血背景效果。

**能用导出的渐变作为视频背景吗？**

可以。启用**乒乓循环**后导出一段短 MP4 或 WebM 视频，然后通过 HTML5 `<video>` 标签配合 `autoplay loop muted playsinline` 属性使用。这是在生产网站中实现动态背景的性能最优方案。
