# 半调效果

半调（Halftone）是最初为印刷复制而开发的技术。GradLab 的半调层将其作为实时后处理效果叠加在渐变上，增添质感、视觉深度和触觉般的模拟质感。

## 什么是半调？

在数字印刷出现之前，连续调图像（照片、绘画）无法直接用油墨复制。半调通过将图像分解为一组圆点来解决这个问题——较大的圆点代表较暗的区域，较小的圆点代表较亮的区域。从一定距离观看时，这种图案会呈现出连续调的视觉效果。

这项技术本身演变为一种视觉语言，代表着：
- **波普艺术**（Roy Lichtenstein 的超大圆点网格）
- **漫画书和新闻纸**（粗糙的 CMYK 半调图案）
- **Risograph 印刷**（不完美的、有质感的圆点复制）
- **复古平面设计**（圆点图案作为审美纹理）

## GradLab 中的半调

GradLab 的半调层与传统印刷半调的工作方式不同。它在渐变上叠加几何图案，在呈现纹理的同时让色彩构图透出来。

### 启用半调

在面板中切换**半调效果**开关，效果会立即出现在当前渐变上。

### 控制参数

| 参数 | 作用 |
|------|------|
| **Type（类型）** | 图案样式：圆点、线条或交叉线 |
| **Size（大小）** | 图案元素的比例 |
| **Shape（形状）** | 圆点形状：圆形、方形、菱形、三角形 |
| **Contrast（对比度）** | 图案元素与渐变的对比强度 |

### 混合模式

半调层通过混合模式合成在渐变上。改变混合模式决定图案与下方渐变颜色的交互方式。**Multiply（正片叠底）**和 **Overlay（叠加）**产生丰富的颜色交互；**Normal（正常）**给出平铺叠加效果。

## 设计应用

**在平滑渐变上增加质感。** 细腻的半调圆点网格让渐变读起来像印刷品或手工制品——适用于需要物质感的品牌资产。

**复古和模拟美学。** 高对比度的粗糙圆点或线条图案创造出 Risograph 印刷、丝网印刷或早期数字图形的外观。

**深度和维度感。** 低不透明度的半调暗示网格或织物纹理，而不会压制渐变颜色。

**混合媒介。** 将胶片颗粒（来自后期处理）与半调结合，创造出读起来真实如模拟效果的多层质感。

## 使用技巧

- 将 **Size** 从 20–30 左右开始调整——尺寸过小读起来像噪点，过大则变得抽象几何
- 使用低 **Contrast** 值（0.3 以下）获得纹理而不让图案主导构图
- **Multiply（正片叠底）** 混合模式适合深色圆点叠加在浅色渐变上；深色渐变上的浅色图案可尝试 **Screen（滤色）**
- 与 ASCII 矩阵层结合，创造完全分层的字符纹理效果
