## Overview

The ASCII Matrix renders a full-canvas grid of characters over the gradient layer. Characters respond to mouse proximity in real time — brightening, shifting, or decaying based on where the cursor moves — creating a dynamic, interactive typographic texture.

The matrix runs on a separate canvas layer composited over the WebGL output, keeping it visually controllable without affecting the underlying gradient animation.

## Character Sets

Choose which characters populate the grid:

| Charset | Characters | Character |
|---------|-----------|-----------|
| **Code** | A scrolling code snippet (`import`, `Engine`, `applyForce`…) | Technical, developer aesthetic |
| **Standard** | `@%#*+=-:. ` | Classic ASCII brightness mapping |
| **Blocks** | `██▓▒░ ` | Chunky, graphic block shading |
| **Detailed** | Full 70-character luminance ramp | Maximum tonal detail |
| **Minimal** | `·■ ` | Ultra-sparse, geometric |
| **Binary** | `01` | Data / cyberpunk feel |
| **Custom** | Your text | Brand name, keyword, any string |

### Custom Charset

Enter any text in the custom field — a brand name, a phrase, a single repeated character — and the matrix tiles it across the canvas. Combined with a large font size, this is an effective way to embed text as texture.

## Mouse Interaction

Move the cursor over the canvas to activate the heatmap. Characters within the **Interaction Radius** respond with increased brightness and animation activity. The effect decays over time based on the **Decay** setting.

| Parameter | Effect |
|-----------|--------|
| **Radius** | Size of the interaction zone around the cursor |
| **Decay** | How quickly characters return to their resting state after the cursor leaves |
| **Smooth** | Easing on the interaction response — higher values produce a softer, more gradual activation |
| **Gravity** | Pulls activated characters toward the cursor position; at 0 characters stay in place |

## Display Controls

| Parameter | Effect |
|-----------|--------|
| **Size** | Font size of each character cell |
| **Spacing** | Line-height multiplier — tighter values pack characters closer vertically |
| **Font** | Selects from a set of monospaced typefaces to match the desired aesthetic |
| **Color** | The fill color of the characters |
| **Blend Mode** | How the character layer composites over the gradient |

## Blend Modes

The matrix layer supports all standard canvas blend modes. The most useful combinations:

| Blend Mode | Effect |
|------------|--------|
| **Overlay** | Characters take on the gradient's hue — natural integration |
| **Screen** | Characters always lighten — works well on dark gradients |
| **Multiply** | Characters always darken — works well on light gradients |
| **Normal** | Flat character color over the gradient, no blending |

## Interaction Mode

Switch between two interaction modes:

| Mode | Description |
|------|-------------|
| **Heatmap Decay** | Characters brighten on cursor contact, then fade back — decay leaves a glowing trail |
| **Dynamic Background** | The full character grid animates continuously; cursor interaction shifts character density rather than brightness |

<Tip>
  For landing page hero sections, try **Code** charset at a medium size with **Overlay** blend and a 20% decay — it creates a living background texture that doesn't compete with foreground text.
</Tip>
