## GradLab 是什么

GradLab 是一款**免费的在线 WebGL 渐变生成器**，完全运行于浏览器端。它通过 GPU 加速着色器实时生成动态渐变效果，无需服务器、无需安装、无需注册账号。

与常见的 CSS 渐变工具不同，GradLab 基于 **OKLab 感知色彩空间**进行颜色混合，确保所有色相组合下的过渡效果均匀自然，开箱即得专业级渐变品质。

## 适用人群

- **UI/UX 设计师** — 为落地页、Hero 区域和应用界面创作流体动态渐变背景
- **品牌设计师** — 从图片中提取品牌色，混合生成流体渐变，导出为 PNG 或视频
- **前端开发者** — 导出独立 HTML 代码片段，通过 `<iframe>` 嵌入任意网站
- **动效设计师** — 录制带乒乓循环的 MP4，用于无缝循环的社交媒体内容
- **创意编程爱好者** — 以 13 种算法为画布，探索流体与几何视觉的边界

## 核心功能

### 流体渐变算法

GradLab 内置 13 种流动算法，每种产生截然不同的视觉结构：

- **流体力学** — 基于分层噪声的湍流有机运动
- **域扭曲** — 通过迭代 UV 变形产生大理石纹理
- **卷曲噪声** — 无散度漩涡流场
- **径向等高线** — 同心渐变环，类似等高线地图
- **嵌套 SDF 形态** — 基于有符号距离场的几何光晕
- **弥散流体** — 将背景图片融入渐变流场

所有算法均以 GLSL 片段着色器直接运行于 GPU。

### OKLab 渐变混色

大多数渐变工具在 sRGB 空间混色，混合互补色时会产生暗沉浑浊的中间区域。GradLab 通过 **OKLab** 感知均匀色彩空间处理所有混色运算，确保每一步过渡都平滑自然。也可切换至 RGB 混色模式。

### 半调叠加

在任意渐变上叠加抖动半调图层，可选 4 种抖动矩阵（随机、2×2、4×4、8×8 Bayer 矩阵）与 6 种点形状（圆形、方形、菱形、线条、十字、椭圆），实现印刷风、复古数字或编辑排版美学。

### 交互式 ASCII 字符矩阵

在画布上叠加全屏 ASCII 字符网格，字符实时响应鼠标位置变化。支持代码片段、方块字符、二进制或自定义文本，字符随光标接近而点亮，离开后衰减，形成动态文字纹理。

### 导出方式

| 格式 | 适用场景 |
|------|----------|
| **PNG** | 设计稿、印刷、社交媒体静态素材 |
| **MP4 / WebM** | 循环视频背景、社交媒体内容 |
| **独立 HTML** | 通过 `<iframe>` 嵌入任意网站的实时渐变 |

所有导出均以最低 2× 像素密度渲染，确保在各设备上清晰呈现。
