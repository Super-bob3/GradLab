# 社交媒体渐变背景

设计得当的渐变背景能让社交内容在信息流中脱颖而出。GradLab 可生成适合各大平台的高分辨率渐变图片和视频。

## 各平台尺寸

在导出前，将 GradLab 的画布尺寸设置为目标平台的标准：

| 平台 | 格式 | 尺寸 |
|------|------|------|
| Instagram 帖子 | 方形 | 1080 × 1080 px |
| Instagram Story / Reels | 竖版 | 1080 × 1920 px |
| X（Twitter）配图 | 横版 | 1200 × 675 px |
| X 主页横幅 | 横幅 | 1500 × 500 px |
| 微博配图 | 横版 | 1080 × 810 px |
| 小红书 | 竖版 | 1080 × 1440 px |
| LinkedIn 帖子 | 横版 | 1200 × 628 px |
| LinkedIn 横幅 | 横幅 | 1584 × 396 px |
| YouTube 缩略图 | 横版 | 1280 × 720 px |

在**画布** W 和 H 字段输入对应数值，然后点击**下载当前帧**导出正确尺寸的 PNG。

## 社交内容技巧

### 使用品牌色

使用**上传图片**功能从 logo、宣传照片或现有品牌素材中提取调色板，确保渐变与视觉体系保持一致。

### 胶片颗粒增添高级感

以低数值（0.1–0.2）启用**后期处理 → 胶片颗粒**。微妙的质感让渐变显得不那么数字化，更有设计感。

### 为 Story 和 Reels 制作动画

导出视频内容：
1. 将画布设置为 1080 × 1920（竖版）
2. 启用 **Ping-pong Loop**
3. 点击**录制 MP4**，录制 3–6 秒后停止
4. 将视频导入剪辑工具（剪映、Premiere、Final Cut）作为背景层

### 叠加文字

将渐变作为背景层导出，然后在设计工具（Figma、Canva、Photoshop）中添加文字、产品图或叠加元素，渐变提供背景，内容置于其上。

### 同一渐变跨平台复用

设计一个渐变，按不同平台尺寸多次导出：1:1、9:16、16:9，在各格式间建立统一的视觉识别。

## 快速导出流程

1. 打开 [GradLab](https://gradlab.app)
2. 设置目标平台的画布尺寸
3. 选择配色并调整动画
4. 点击**下载当前帧**获取静态 PNG
5. 导入到设计或内容工具中
