# 调色板

调色板面板是每个渐变的基础。GradLab 使用 **OKLab 感知色彩空间**在画布上混合你选择的颜色，在所有颜色位置保持亮度平衡与饱和度，避免标准 RGB 混色常见的浑浊中间色。

## 添加与删除颜色

- 点击 **+** 添加新颜色（最多 8 个）
- 点击色块上的 **×** 删除颜色（最少保留 2 个）
- 颜色按面板中的排列顺序渲染

## 排序

左右拖拽色块即可调整混色顺序，画布实时更新。

## 颜色选择器

点击色块打开颜色选择器：

- 在**色相/饱和度/明度**渐变区域拖拽选色
- 直接在输入框中输入**十六进制色值**
- 取消时选择器会记住上一次的颜色

## 混色模式

**混色模式**切换两种颜色插值方式：

| 模式 | 说明 |
|------|------|
| **OKLab** | 感知均匀 — 所有色相组合下均平滑鲜明 |
| **RGB** | 标准线性插值 — 互补色混合时可能出现浑浊中间色 |

OKLab 是默认推荐模式。

## 混色偏移与锐度

- **混色偏移** — 调整插值中点位置：向 0 偏移时渐变向第一个颜色倾斜，向 100 偏移时向最后一个颜色倾斜
- **混色锐度** — 控制颜色过渡的突变程度；数值越高，颜色带越分明，而非平滑渐变

## 图片取色

点击颜色列表旁的**图片图标**上传照片，GradLab 会自动提取图片中的主要颜色并填充到调色板。

::: tip
试试上传一张日落照片或设计参考图 — 提取的调色板往往能给出手动调整需要几分钟才能达到的渐变起点。
:::
