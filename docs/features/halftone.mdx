## Overview

The Halftone layer converts the continuous gradient into a pattern of discrete dots or shapes, mimicking traditional print halftone screens. It's rendered as a GPU compositing pass over the base gradient, giving you full control over density, shape, and contrast without affecting the underlying animation.

## Dither Matrix

The dither matrix controls how luminance thresholds are calculated across each halftone cell:

| Matrix | Character |
|--------|-----------|
| **Random** | Stochastic noise — irregular, organic dot placement with no visible grid |
| **2×2 Ordered** | A 2-cell Bayer matrix — visible grid structure, retro digital feel |
| **4×4 Ordered** | A 16-step Bayer matrix — smoother tonal range with a classic halftone grid |
| **8×8 Ordered** | High-precision Bayer matrix — fine dot control, closest to commercial print halftone |

## Dot Shape

Six shapes define the geometry of each halftone cell:

| Shape | Description |
|-------|-------------|
| **Circle** | Classic halftone dot — the most common print and editorial look |
| **Square** | Hard-edged blocks — bold, graphic, pixel-art adjacent |
| **Diamond** | 45° rotated square — produces a distinctive angular grid |
| **Line** | Parallel stripes — resembles mezzotint or engraving screens |
| **Cross** | Star-shaped dots — decorative, maximalist texture |
| **Ellipse** | Horizontally stretched dots — softer than circle, more directional |

## Size

Controls the diameter of each dot cell. Smaller values produce fine, high-frequency halftone screens; larger values produce bold, chunky dots that read clearly at a distance.

## Contrast

Shifts the luminance threshold at which dots appear, effectively brightening or darkening the overall halftone layer. Increase contrast to push dots toward full-on or full-off; decrease to preserve gradient tonal nuance within the pattern.

<Tip>
  Combine **8×8 Ordered** dither with **Circle** shape and a low contrast setting to get the closest result to traditional offset print halftone. Pair with a two-color palette for a spot-color print aesthetic.
</Tip>

## Use Cases

- **Editorial design** — halftone backgrounds for magazine-style layouts
- **Risograph / screen print** — simulate ink-on-paper printing aesthetics
- **Brand visuals** — add texture and depth to gradient backgrounds without complex illustrations
- **Retro UI** — combine with a limited palette for a nostalgic digital feel
