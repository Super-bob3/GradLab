## Overview

GradLab is a browser-based creative tool for generating high-quality gradient visuals. It combines a GPU-accelerated WebGL shader engine with a precision color pipeline built on the **OKLab perceptual color space**, ensuring every blend looks natural regardless of hue.

Whether you're crafting a visual identity background, a motion loop for social media, or an interactive art piece, GradLab gives you professional-grade controls without any installation.

## Why GradLab

Most gradient tools work in sRGB space, which causes muddy or overly dark blends when mixing complementary colors. GradLab routes every color operation through **OKLab** — a perceptually uniform color space — so transitions remain vivid and balanced at every step.

The rendering pipeline runs on your GPU via WebGL, meaning:

- **No server round-trips.** Every parameter change is rendered locally, instantly.
- **No installation.** Open the URL and start creating.
- **High resolution output.** Renders at 2× device pixel ratio minimum for crisp exports on all platforms.
