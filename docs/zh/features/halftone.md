# 半调

半调图层将连续渐变转换为离散点阵图案，模拟传统印刷半调网屏。它以 GPU 合成通道渲染于基础渐变之上，在不影响底层动画的前提下完全控制密度、形状和对比度。

## 抖动矩阵

| 矩阵 | 特点 |
|------|------|
| **随机** | 随机噪声 — 不规则的有机点阵分布，无可见网格 |
| **2×2 有序** | 2 格 Bayer 矩阵 — 可见网格结构，复古数字感 |
| **4×4 有序** | 16 阶 Bayer 矩阵 — 更平滑的色调范围，经典半调网格 |
| **8×8 有序** | 高精度 Bayer 矩阵 — 精细的点控制，最接近商业印刷半调 |

## 点形状

| 形状 | 说明 |
|------|------|
| **圆形** | 经典半调圆点 — 最常见的印刷和编辑排版风格 |
| **方形** | 硬边方块 — 粗犷、图形感、像素艺术风 |
| **菱形** | 45° 旋转方块 — 独特的斜向网格 |
| **线条** | 平行条纹 — 类似美柔汀或雕刻网屏 |
| **十字** | 星形点阵 — 装饰性、繁复质感 |
| **椭圆** | 水平拉伸的点 — 比圆形更柔和，更具方向感 |

## 大小

控制每个点格的直径。数值越小，半调网屏越精细；数值越大，点阵越粗犷，远看也清晰可辨。

## 对比度

调整点阵出现的亮度阈值。提高对比度使点阵趋向全开或全关；降低对比度保留渐变在图案内的色调细节。

::: tip
**8×8 有序**抖动 + **圆形**点 + 低对比度，最接近传统胶印半调效果。配合双色调色板，可实现专色印刷美学。
:::

## 使用场景

- **编辑排版** — 杂志风格的半调背景
- **Risograph / 丝网印刷** — 模拟油墨在纸张上的印刷质感
- **品牌视觉** — 为渐变背景增加纹理和深度
- **复古 UI** — 配合有限色板，打造怀旧数字风格
