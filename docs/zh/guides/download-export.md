# 如何下载和导出渐变

GradLab 提供三种导出方式，分别适用于不同场景。本指南介绍每种格式的使用时机和最佳设置。

## PNG——下载静态图片

**适用场景：** 静态设计稿、社交媒体发帖、UI 原型图、印刷品、演示文稿。

1. 在画布上完成渐变设计
2. 点击面板中的**下载当前帧**
3. `.png` 文件即时下载

**分辨率：** GradLab 以最低 2× 设备像素比渲染。在 Retina 屏幕上，1280 × 720 的画布会导出为 2560 × 1440，始终保证高分辨率输出。

::: tip
导出前先在**画布**区域设置好目标尺寸，确保 W 和 H 与使用场景匹配。
:::

## MP4——下载渐变视频

**适用场景：** 网站 Hero 区视频背景、社交媒体视频、动态演示文稿、动效素材。

1. 在面板中启用 **Ping-pong Loop**（推荐，可生成无缝循环）
2. 点击**录制 MP4**
3. 让动画运行所需时长（3–8 秒为宜）
4. 点击**停止录制**
5. GradLab 编码完成后自动下载 `.mp4` 文件

**格式：** Chrome 和 Edge 导出 MP4（H.264）；Safari 回退为 WebM（VP8），两种格式均兼容所有现代浏览器。

::: info
Ping-pong Loop 会让动画正放后再倒放，形成无剪切点的完美循环。
:::

**缩小文件体积的技巧：**
- 录制 4–6 秒而非更长
- 网络使用时画布建议不超过 1280 × 720
- 录制前降低 **Speed** 滑块，获得更平缓、压缩率更高的视频

## HTML——下载独立渐变文件

**适用场景：** 嵌入网页、分享保持动画的渐变、归档渐变配置。

1. 点击**导出代码**
2. 在弹窗中点击**下载**保存 `.html` 文件

导出的文件完全独立——包含 WebGL 着色器、所有参数值和渲染循环，无外部依赖，可离线在任何浏览器中打开。

**导出 HTML 的使用方式：**

| 使用场景 | 方法 |
|----------|------|
| 嵌入网站 | 通过 `<iframe>` 引用 |
| 全屏背景 | 直接在浏览器标签页中打开 |
| 分享给客户 | 发送单个文件，对方可在任意浏览器打开 |
| 归档配置 | 所有渐变参数均已内嵌 |

```html
<iframe
  src="your-gradient.html"
  style="width:100%; height:100%; border:none;"
></iframe>
```

## 参数代码下载

导出代码弹窗底部的**下载参数代码**按钮会保存一个仅包含参数值的紧凑 JSON 文件，可用于保存和恢复特定渐变配置，而无需包含完整着色器代码。

## 导出格式对比

| 格式 | 文件类型 | 动画 | 依赖 | 适用场景 |
|------|----------|------|------|----------|
| PNG | `.png` | 否 | 无 | 静态设计、印刷 |
| 视频 | `.mp4` / `.webm` | 是 | 无 | 网站背景、社交视频 |
| HTML | `.html` | 是 | 无 | 网页嵌入、分享 |
